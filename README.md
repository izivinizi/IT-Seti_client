## О проекте

ITSeti Maintenance собирает показатели компьютера, проверяет накопители и
показывает понятные причины возможных проблем. Пользовательский экран рассчитан
на самостоятельную базовую проверку; режим инженера содержит полную диагностику,
историю и обслуживание Windows.

Текущая версия проекта: **0.6.0**.

## Возможности

| Пользователь | Инженер |
| --- | --- |
| CPU, ОЗУ, диски, свободное место и время после перезагрузки | Полная сводка оборудования, процессов, SMART и журналов Windows |
| Проверка SMART и скорости без открытия дисковых утилит | Полный и ускоренный диагностические прогоны |
| Возможные причины замедления простым языком | История результатов, сравнение проверок и отладочные журналы |
| Очистка корзины и временных файлов | Очистка, DISM/SFC, проверка обновлений и политика автообновлений |

Дисковые тесты используют CrystalDiskInfo и DiskSpd из комплекта
CrystalDiskMark. Измерение чтения проходит два раза; запись отображается, но не
оценивается. Для HDD приложение отдельно поясняет ожидаемо более медленный запуск
программ. При низком свободном месте можно открыть TreeSize Free для ручного
анализа.

## Пороговые значения

| Показатель | Предупреждение | Критично |
| --- | ---: | ---: |
| Свободное место на разделе | меньше 15 ГБ | меньше 5 ГБ |
| Чтение SATA SSD | меньше 210 МБ/с | меньше 180 МБ/с |
| Чтение NVMe SSD | меньше 900 МБ/с | меньше 180 МБ/с |
| Чтение HDD | меньше 100 МБ/с | меньше 80 МБ/с |
| CPU / ОЗУ | не менее 90% в большинстве замеров за 30 секунд | ОЗУ почти исчерпана и наблюдается активная подкачка |
| Общая ОЗУ | 4 ГБ или меньше | — |

Порог скорости — повод перепроверить компьютер при обычной нагрузке, а не
самостоятельный диагноз неисправности. Для SATA/PCIe выводится ограничение
режима подключения, если CrystalDiskInfo показывает более быстрый режим,
поддерживаемый самим диском; возможности порта ПК неизвестны.

Windows ниже сборки 17763 (версия 1809) получает предупреждение. Если Windows не
отображает версию или SMART недоступен, это показывается как отсутствие данных,
а не как исправное состояние.

## Плановое обслуживание

При установке регистрируются системные задачи Windows. Раз в 14 дней запускается
короткая проверка с SMART без 30-секундного замера и теста скорости. Новая
проблема показывается пользователю при следующем входе в Windows. Раз в 60 дней
запускается полная проверка с DISM/SFC. Пользовательская полная проверка выполняет
диагностику инженера, но не запускает очистку или восстановление.

Во время полной инженерной проверки и по отдельной кнопке приложение задаёт
политику Windows, запрещающую автоматическую установку обновлений. Проверить
обновления можно отдельно; установка не выполняется. Предусмотрена кнопка возврата
сохранённого исходного значения. Доменная групповая политика может переопределить
локальную настройку. При удалении приложения исходная настройка восстанавливается,
если её не меняли извне.

Установщик требует администратора один раз для установки файлов и системных задач.
Обычный запуск, проверки и запуск утверждённых задач не должны запрашивать пароль
администратора повторно. Приложение не хранит пароль административной учётной
записи.

## Обновление приложения

Во время полной диагностики приложение без блокировки проверяет публичный
[последний стабильный релиз](https://github.com/izivinizi/IT-Seti_client/releases).
Во вкладке «ПО» доступны повторная проверка и кнопка «Обновить». Установщик
скачивает фиксированная задача Windows от `SYSTEM`, созданная при установке;
перед запуском она сверяет SHA-256 с метаданными GitHub, принимает только
`ITSeti-Maintenance-Setup.exe` из этого репозитория и тихо устанавливает новую
версию после закрытия приложения. Пароли и GitHub-токены не используются.

Установщик приложения по-прежнему требует права администратора один раз, чтобы
создать системные задачи. Обычный запуск проверки и запрос обновления не должны
повторно показывать UAC. Если задача отсутствует, приложение сообщает, что нужна
переустановка; оно не запускает повышение прав самостоятельно.
Для перехода с выпусков до 0.6.0 новый установщик нужно запустить один раз вручную:
старые версии ещё не содержат задачу обновления.

## Сборка

Требуются Visual Studio 2022 или .NET 9 SDK; для установщика также Inno Setup 6.
Комплект дисковых утилит и TreeSize находится в `ITSeti.Maintenance/Tools`.

```powershell
dotnet build ITSeti.Maintenance/ITSeti.Maintenance.sln
dotnet run --project ITSeti.Maintenance/tests/ITSeti.Maintenance.Smoke
pwsh -File ITSeti.Maintenance/Build-InstallPackage.ps1
```

Установщик собирается в `ITSeti.Maintenance/dist/ITSeti-Maintenance-Setup.exe`.
Устанавливать или тестировать его на рабочем компьютере без отдельной приёмки
системных задач и прав доступа не следует.

## Сторонние утилиты

В проект включены исходные дистрибутивы CrystalDiskInfo, CrystalDiskMark и
TreeSize Free вместе с файлами лицензий. CrystalDiskInfo и CrystalDiskMark можно
распространять по условиям их лицензий; TreeSize Free распространяется только
неизменённым и бесплатно, согласно
[лицензии JAM Software](https://www.jam-software.com/company/license_agreement.shtml).
На Windows Server TreeSize Free не запускается. Не удаляйте лицензионные файлы
из комплекта.

Исходники приложения, включая необходимые backend-компоненты, находятся в
`ITSeti.Maintenance`. Отдельный переносной комплект обслуживания в этот репозиторий
не входит. Подробности сборки и установки: [ITSeti.Maintenance/README.md](ITSeti.Maintenance/README.md).
