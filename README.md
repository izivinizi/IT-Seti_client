Приложение показывает состояние компьютера, помогает собрать понятные данные для
обращения в ИТ-Сети и предоставляет инженеру подробные инструменты диагностики.
Проверки не отправляют отчёты на сервер: результаты и история хранятся на ПК.

![Пользовательский экран. ID в изображении тестовые](ITSeti.Maintenance/docs/images/user-home.png)

## Быстрый старт

1. Скачайте `ITSeti-Maintenance-Setup.exe` со страницы [релизов](https://github.com/izivinizi/IT-Seti_client/releases/latest).
2. Запустите установщик с правами администратора. Они нужны один раз, чтобы поставить приложение и зарегистрировать фоновые задачи Windows.
3. На одном экране выберите папку приложения, укажите четырёхзначный инвентарный номер и при необходимости подключите комплект программ ИТ-Сети.
4. Запустите приложение с рабочего стола или из меню «Пуск». Для обычной пользовательской проверки вводить пароль администратора не нужно.

Установщик предназначен для Windows 10/11 x64. Для Windows 7 оставлена отдельная
скриптовая версия. Если политика домена запрещает регистрацию обязательных задач,
установщик покажет ошибку и сохранит подробности в
`C:\ProgramData\ITSeti\Maintenance\install.log`.

## Пользовательский режим

На главном экране находятся три действия: проверка компьютера, очистка и заявка.
Показатели CPU, памяти, системного диска и температуры обновляются автоматически.

### Проверка

Полная пользовательская проверка сопоставима с инженерской диагностикой и включает
SMART и измерение скорости накопителя. Она показывает ход работы и краткие
результаты: загрузку процессора и памяти, свободное место, температуру, состояние
дисков и причины возможных проблем. Проверка не запускает очистку и восстановление
Windows. Если после входа в систему прошло больше шести дней, приложение предложит
перезагрузить ПК и напомнит сохранить документы; само компьютер не перезагружает.

### Очистка

Кнопка очищает корзину и временные файлы текущего пользователя, а также системные
временные данные, кэш эскизов и шейдеров, файлы оптимизации доставки, пакеты драйверов
и доступные файлы очистки обновлений Windows. Системная часть выполняется фоновой
задачей. Документы, загрузки и пользовательские данные браузеров не удаляются.

### Оставить заявку

Окно показывает способы связи с поддержкой: MAX, электронную почту, Telegram и
телефон. Заявка отправляется через выбранный канал. Инвентарный номер, RMS ID и
публичный ID AnyDesk можно выделить мышью, скопировать по отдельности или собрать
одной кнопкой «Копировать всё».

![Окно заявки и копирования данных ПК. Идентификаторы на снимке тестовые](ITSeti.Maintenance/docs/images/support-dialog.png)

## Режим инженера

Нажмите значок замка справа вверху. Окно пользователя останется открытым, а инженерская
панель откроется отдельно. Для повышенных прав Windows проверяет введённую учётную
запись и пароль. Приложение не хранит пароль Windows. Если вход не проходит,
используйте пароль учётной записи, а не PIN-код Windows Hello.

| Вкладка | Что находится внутри |
| --- | --- |
| **Обзор** | CPU, видеокарта, тип памяти DDR, загрузка и системный диск; сохранение инвентарного номера; краткие факты, требующие внимания |
| **Накопители** | Физические диски и разделы, SMART, свободное место, тип подключения и наработка |
| **Сеть** | Активные физические адаптеры, VPN, скорость линка и IP-адреса; отключённые и служебные интерфейсы скрыты |
| **Процессы** | Процессы вне встроенного списка доверенных издателей, с названием и издателем |
| **События** | Журнал Windows; по умолчанию показаны критические события, фильтр переключается на ошибки и все уровни |
| **ПО** | Установка или удаление AnyDesk, RMS, OCS и панели ИТ-Сети; запуск CrystalDiskInfo, CrystalDiskMark и TreeSize; обновление приложения и открытие `Tools.rar` |
| **История** | Предыдущие проверки, конкретные найденные замечания и сравнение ключевых изменений |
| **Отладка** | Этапы последней проверки, ошибки запуска, причины отсутствия данных и журналы |
| **Обслуживание** | Системные инструменты, очистка, DISM/SFC, обновления Windows, восстановление исходной политики и состояние Microsoft Defender |
| **Ход проверки** | Текущая загрузка CPU/ОЗУ, SMART и измерения диска по мере выполнения |

Кнопки ПО используют установленную системную задачу, зарегистрированную инсталлятором.
Если соответствующая задача заблокирована политикой Windows, инженер увидит причину в
статусе или вкладке «Отладка». Сторонние окна запускаются в интерактивном сеансе
инженера. TreeSize открывает анализ выбранного тома.

### Показатели и пороги

- CPU и ОЗУ: длительная средняя загрузка от 90% за 30 секунд считается высокой; единичный скачок не становится предупреждением. Для ОЗУ менее 4 ГБ показывается отдельное замечание. При нехватке памяти выводятся три процесса с наибольшим потреблением.
- Температура процессора: выше 80 °C — предупреждение, 90 °C и выше — критический уровень. Если датчик или драйвер недоступен, приложение сообщает об этом, не подменяя температуру другим датчиком.
- Свободное место: менее 15 ГБ — предупреждение, менее 5 ГБ — критический уровень.
- Скорость чтения: для SATA SSD ниже 210 МБ/с — предупреждение, ниже 180 МБ/с — критический уровень; для NVMe ориентир 900 МБ/с; для HDD — 100 и 80 МБ/с соответственно. Скорость записи показывается справочно. HDD отдельно отмечается как более медленный тип накопителя.
- Наработка диска свыше 60 000 часов отмечается как высокая. Тревожный SMART и подтверждённое ограничение режима подключения показываются отдельно.
- Установленная редакция Windows ниже 1809 (18H2) получает предупреждение о старой версии.

Пороговые значения служат ориентиром обслуживания, а не диагнозом неисправности.
Скорость зависит от модели накопителя, интерфейса, фоновой нагрузки и свободного
места; для HDD возможны заметные колебания.

## ПО и обновление

Во вкладке «ПО» каждый компонент ИТ-Сети устанавливается отдельно; для уже
обнаруженного компонента доступно удаление. «Установить всё» предлагает доступные
сценарии. Компоненты и установщики сверяются с закреплёнными SHA-256 до запуска.
Если комплект отсутствует или в нём не хватает файлов, приложение сообщает, что
именно недоступно, вместо имитации успешной установки.

Кнопки дисковых утилит запускают их из папки приложения. `Tools.rar` остаётся
зашифрованным архивом: пароль вводится в установленной пользователем программе-архиваторе,
приложение его не знает и не сохраняет.

Кнопка «Проверить обновления» получает сведения о последнем публичном релизе GitHub.
«Обновить» скачивает установщик системной задачей, проверяет размер и SHA-256, затем
запускает установку. Результат отображается после следующего запуска приложения.
Проверка выпуска не зависит от лимита GitHub API.

## Обслуживание и расписание

- Каждые 14 дней приложение предлагает быструю проверку отдельным окном; её можно запустить сразу или отложить на один день.
- Полная проверка с восстановлением системных файлов запланирована раз в 60 дней.
- DISM/SFC также можно запустить вручную во вкладке «Обслуживание». Результат и журнал доступны там же.
- Полная инженерская проверка управляет автоустановкой обновлений Windows согласно сохранённой политике; состояние можно проверить и настройку вернуть во вкладке обслуживания. Доменная политика может иметь приоритет.
- Microsoft Defender включается или отключается вручную инженером с подтверждением. Переключатель меняет только защиту в реальном времени и не обходит Tamper Protection или политику организации.

Длительные очистка и восстановление работают отдельно от интерфейса: их статус
можно проверить позже, а окно приложения закрыть или использовать для другой проверки.

## Где хранятся данные

- История проверок: `%LOCALAPPDATA%\ITSeti\Maintenance\history.db`.
- Отчёты и журналы диагностических запусков: `%LOCALAPPDATA%\ITSeti\Maintenance\Runs`.
- Инвентарный номер и состояние обслуживания: `%ProgramData%\ITSeti\Maintenance`.
- Ошибки установки: `C:\ProgramData\ITSeti\Maintenance\install.log`.

Приложение не отправляет результаты проверок, журналы или список процессов в GitHub
или ИТ-Сети. Интернет нужен для ручной проверки и загрузки обновления. Инвентарный
номер, RMS и AnyDesk считываются локально и показываются только в интерфейсе заявки.

## Сборка из исходников

Откройте `ITSeti.Maintenance/ITSeti.Maintenance.sln` в Visual Studio 2022 или выполните:

```powershell
dotnet build ITSeti.Maintenance/ITSeti.Maintenance.sln -c Release
dotnet run --project ITSeti.Maintenance/tests/ITSeti.Maintenance.Smoke
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ITSeti.Maintenance/Build-InstallPackage.ps1
```

Для установщика нужны .NET 9 SDK и Inno Setup 6. Лицензии и уведомления о сторонних
компонентах собраны в [THIRD-PARTY-NOTICES.md](ITSeti.Maintenance/THIRD-PARTY-NOTICES.md).
