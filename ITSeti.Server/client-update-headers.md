# Заголовки обнаружения обновлений

Успешные ответы `/api/v1/*`, прошедшие проверку ключа устройства или ключа поддержки, содержат:

- `X-ITSeti-Application-Version`: актуальная версия пакета `application` выбранной платформы. Если пакета нет либо версия некорректна, заголовок отсутствует.
- `X-ITSeti-Catalog-Revision`: SHA-256 метаданных актуальных пакетов выбранной платформы и `any`. Значение непрозрачное: сравнивать только равенство.

Платформа: query `platform=windows|win7`, затем `X-ITSeti-Platform`, затем сведения об ОС устройства (Windows 7/6.1 → win7, иначе windows). Некорректная явно указанная платформа подавляет подсказки. Win7 никогда не получает modern application как резервный вариант.

Ответы без авторизации, публичный каталог регистрации, редиректы и HTTP-ошибки не содержат этих заголовков. Клиент должен сохранять штатный fallback, если заголовков нет; заголовки только сигнализируют о необходимости проверить штатный endpoint обновлений и не заменяют проверку версии/хеша установщика.

Общий кеш: 10 секунд; успешные загрузка, активация и удаление пакета сбрасывают кеш до отправки ответа администратора. Изменения напрямую в БД становятся видны не позднее следующего обновления кеша. Ошибка получения необязательных подсказок не отменяет основной ответ.

Проверено 17 октября 2026: Release build, PostgreSQL update hints tests, существующие серверные тесты. HTTP: modern/Win7/support-key, отсутствие подсказок при 401/400/публичном доступе/неизвестной платформе; переключение пакета с прогретым кешем немедленно меняет версию и ревизию. Тестовая база отдельная, рабочая не изменялась.
