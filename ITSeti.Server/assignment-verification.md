# Автоматический выбор объекта · 17 октября 2026

- Компания без объекта: выбирается единственный активный объект этой компании.
- При нескольких объектах используется единственная активная привязка недавних ПК с тем же IP внутри той же компании. Сам ПК исключается из сопоставления.
- Чужие компании, неактивные объекты и сведения старше 120 дней не используются. Несколько разных объектов не дают автоматического выбора.
- Существующий выбранный объект сохраняется. Адрес и название не являются ключами: привязка хранит ID объекта Okdesk.
- Инвентарник, совпавший с ПК без объекта и оборудованием той же компании с объектом, больше не теряет однозначную привязку оборудования.
- Завершение привязки применяется к auto-enroll и assignment/resolve; при повторной регистрации дополненный объект записывается в БД.

Проверка: Release build без предупреждений; PostgreSQL AssignmentDatabaseChecks в одноразовой базе; существующие серверные тесты. Дополнительно реальные HTTP auto-enroll (первичная и повторная регистрация), assignment/resolve, чужая компания на том же IP и конфликт объектов. Рабочая БД не изменялась.
