## Границы проверки

Цветовые пороги интерфейса HWiNFO не передаются общим полем Shared Memory. Аппаратные флаги и состав датчиков зависят от конкретной платы; их обработка проверена сценариями и на доступном тестовом ПК, без намеренного перегрева оборудования.

Сборка Windows 7, её диагностика и парсер обновлений проверены под .NET Framework на текущем Windows-хосте. Отдельной машины с Windows 7 для проверки запуска нет; пакет сохраняет существующий статус Win7 beta. Windows 7 не предоставляет интерфейс заявок.

Время повторной установки на других ПК зависит от накопителя и содержимого архива. Повторный рекурсивный обход исключён условием миграции; универсальное время установки не обещается.
