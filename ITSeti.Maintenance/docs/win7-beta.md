# Клиент для Windows 7 (beta 2.3.1)

Это отдельный порт текущего клиента с собственным установщиком, исполняемым файлом,
задачами и каталогом отчётов. Он предназначен для Windows 7 SP1 (x86 и x64) и не
заменяет клиент Windows 10/11.

## Требования

- Windows 7 с Service Pack 1, 32- или 64-разрядная.
- .NET Framework 4.8. Если его нет, установщик сам запустит включённый в пакет
  официальный офлайн-установщик Microsoft. На целевом ПК интернет не нужен.
- Права администратора однократно, при установке. Диагностика запускается обычным пользователем.

Если .NET потребует перезагрузку, перезагрузите ПК и запустите установщик ещё раз.
На давно не обновлявшейся Windows 7 может понадобиться поддержка подписи SHA-2
(KB4474419 и KB4490628); в случае ошибки будет показан код .NET-установщика.

Для сборки из каталога `ITSeti.Maintenance`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-Win7Package.ps1
```

Результат: `dist\Win7\ITSeti-Maintenance-Win7-Setup.exe`.

## Что проверяется

Быстрая проверка показывает ОС и время последней загрузки, CPU и ОЗУ, GPU,
серийный и инвентарный номера, RMS/AnyDesk, тома, активные сетевые адаптеры,
процессы и ошибки журналов Windows. Инвентарный номер можно сохранить и вместе
с номерами удалённой поддержки скопировать для заявки. SMART для SATA/HDD запрашивается через
CrystalDiskInfo, который запускает фиксированная задача планировщика от SYSTEM.
Полная проверка дополнительно измеряет последовательное чтение и запись
системного диска через DiskSpd 2.0.15. Тест создаёт временный файл 1 ГБ,
требует минимум 3 ГБ свободного места и может занять несколько минут.
Установщик регистрирует задачи сбора SMART и DiskSpd от SYSTEM. Плановая быстрая
проверка выполняется раз в 14 дней без DiskSpd; плановая полная диагностика и SFC
запускаются раз в 60 дней отдельной задачей. Плановые действия не выполняют обычную
очистку. Пропущенный во время выключения запуск выполняется после включения Windows.
Обычный пользователь может запускать только заранее зафиксированные задачи SYSTEM,
но не менять их команду или EXE.

Вкладки показывают накопители, сеть, процессы, события и историю последних
30 проверок с сопоставлением скорости, места, ошибок и процессов. Вкладка ПО
сверяет установленное ПО с рабочим списком без запуска установщиков. В обслуживании
доступны проверка обновлений Windows и очистка старых файлов Temp текущего
пользователя. Инженерное окно открывается с UAC и содержит системные утилиты,
управление автообновлениями и SFC. После ручной и плановой проверки задача SYSTEM
проверяет публичный манифест основной ветки. Если Win7-релиз новее, установщик
скачивается, сверяется по размеру и SHA-256 и запускается в фоне. При ошибке ночной
полной проверки приложение предложит повторить её днём; быстрая проверка пользователя
не беспокоит. Недоступный показатель не считается исправным. Ручные отчёты хранятся
в профиле пользователя, плановые — в `%ProgramData%\ITSetiMaintenanceWin7`;
отправки на сервер нет.

## Ограничения beta

Автоматической установки ПО нет. Обычная очистка и восстановление не входят в
плановую полную проверку; SFC выполняется отдельным заданием SYSTEM. DISM
/RestoreHealth для Windows 7 недоступен. Температура CPU
появляется только при наличии совместимого источника WMI; драйвер датчиков не
встраивается. CrystalDiskInfo на Windows 7 не поддерживает SMART NVMe, а отдельные
контроллеры могут не отдать SMART вовсе. Состояние в таком случае отмечается
неизвестным. `Yandex.exe` из основного комплекта не переносится: текущий Яндекс
Браузер больше не поддерживает Windows 7. Старый `Service-Win7.ps1` не используется.

Установщик намеренно запускается только на Windows 7 SP1. Сборка и регрессионные
тесты выполняются на более новой Windows; перед массовым развёртыванием следует
проверить установку, SMART и плановые задачи на настоящих Windows 7 x86 и x64.
