# Клиент для Windows 7 (beta)

Это отдельное приложение и отдельный установщик для Windows 7 SP1 (x86 и x64).
Они не меняют основной клиент Windows 10/11 и его задачи.

## Требования

- Windows 7 с Service Pack 1, 32- или 64-разрядная.
- Установленный .NET Framework 4.8.
- Права администратора однократно, при установке. Диагностика запускается обычным пользователем.

[Официальный установщик .NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48).

Для сборки из каталога `ITSeti.Maintenance`:

```powershell
powershell.exe -NoProfile -File .\Build-Win7Package.ps1
```

Результат: `dist\Win7\ITSeti-Maintenance-Win7-Setup.exe`.

## Что проверяется

Клиент получает через WMI версию и время запуска Windows, серийный номер BIOS,
загрузку CPU, свободную память и локальные тома. Также читает последние ошибки
журналов Windows. SMART запрашивается через CrystalDiskInfo, который запускает
фиксированная задача планировщика от SYSTEM. Установщик регистрирует её сам.
Обычный пользователь может запустить задачу и прочитать отчёт, но не менять
команду задачи или исполняемый файл в Program Files. Если задача не зарегистрирована,
установка завершается ошибкой.

Недоступный показатель отмечается как недоступный, а не как исправный. Отчёт
сохраняется в профиле текущего пользователя, его можно скопировать или экспортировать.
На сервер ничего не отправляется.

## Ограничения beta

Пока нет теста скорости диска, очистки, DISM/SFC, обновлений, периодических проверок
и температуры CPU: для неё нужен проверенный источник датчика. CrystalDiskInfo
может не получить SMART от отдельного контроллера; причина будет показана без
запроса пароля администратора. Старый `Service-Win7.ps1` не используется.

Установщик намеренно запускается только на Windows 7 SP1. На настоящем ПК с
Windows 7 ещё нужно проверить установку, задачу SMART из обычной учётки,
диагностику и удаление на x86 и x64 перед массовым развёртыванием.
