# Клиент для Windows 7 (beta 0.3.0)

Это отдельное приложение и отдельный установщик для Windows 7 SP1 (x86 и x64).
Они не меняют основной клиент Windows 10/11 и его задачи.

## Требования

- Windows 7 с Service Pack 1, 32- или 64-разрядная.
- Установленный .NET Framework 4.8.
- Права администратора однократно, при установке. Диагностика запускается обычным пользователем.

[Официальный установщик .NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48).

Для сборки из каталога `ITSeti.Maintenance`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-Win7Package.ps1
```

Результат: `dist\Win7\ITSeti-Maintenance-Win7-Setup.exe`.

## Что проверяется

Быстрая проверка показывает ОС и время последней загрузки, CPU и ОЗУ, GPU,
серийный и инвентарный номера, RMS/AnyDesk, тома, активные сетевые адаптеры,
процессы и ошибки журналов Windows. Инвентарный номер можно сохранить и вместе
с номерами удалённой поддержки скопировать для заявки. SMART для SATA/HDD запрашивается через
CrystalDiskInfo, который запускает фиксированная задача планировщика от SYSTEM.
Полная проверка дополнительно измеряет последовательное чтение и запись
системного диска через DiskSpd 2.0.15. Тест создаёт временный файл 1 ГБ,
требует минимум 3 ГБ свободного места и может занять несколько минут.
Установщик регистрирует обе задачи сам. Обычный пользователь может запускать
только заранее зафиксированные действия, но не менять их команду или EXE.

Вкладки показывают накопители, сеть, процессы, события и историю последних
30 проверок с сопоставлением скорости, места, ошибок и процессов. Вкладка ПО
сверяет установленное ПО с рабочим списком без запуска установщиков. В обслуживании
доступны проверка обновлений Windows и очистка старых файлов Temp текущего
пользователя. Инженерное окно открывается с UAC и содержит системные утилиты,
управление автообновлениями и SFC. Недоступный показатель не считается исправным.
Отчёт хранится в профиле текущего пользователя; отправки на сервер нет.

## Ограничения beta

Нет плановых проверок и автоматической установки ПО/обновления клиента. Полная
проверка пока не выполняет автоматическую очистку и восстановление; SFC запускается
отдельно инженером. DISM /RestoreHealth для Windows 7 недоступен. Температура CPU
появляется только при наличии совместимого источника WMI; драйвер датчиков не
встраивается. CrystalDiskInfo на Windows 7 не поддерживает SMART NVMe, а отдельные
контроллеры могут не отдать SMART вовсе. Состояние в таком случае отмечается
неизвестным. `Yandex.exe` из основного комплекта не переносится: текущий Яндекс
Браузер больше не поддерживает Windows 7. Старый `Service-Win7.ps1` не используется.

Установщик намеренно запускается только на Windows 7 SP1. На настоящем ПК с
Windows 7 ещё нужно проверить установку, задачу SMART из обычной учётки,
диагностику и удаление на x86 и x64 перед массовым развёртыванием.
